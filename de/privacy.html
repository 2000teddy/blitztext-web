2. Gegenstand

Blitztext Lite ist eine macOS-Menüleisten-App für Sprache-zu-Text-Diktation. Die App nimmt gesprochene Sprache per Mikrofon auf, transkribiert sie und stellt das Ergebnis in der macOS-Zwischenablage bereit.

3. Was Blitztext NICHT tut

  • Kein Tracking, keine Telemetrie, keine Nutzungsanalyse
  • Keine Werbung
  • Kein Account, keine Registrierung
  • Kein iCloud-Sync
  • Keine Weitergabe an Dritte — außer an das vom Nutzer gewählte Backend
  • Keine Cookies, keine Geräte-/Nutzer-IDs

4. Welche Daten werden verarbeitet?

4.1 Audioaufnahme

EigenschaftDetails
ErhebungNur während der Nutzer aktiv den Hotkey gedrückt hält
SpeicherortTemporäre .m4a-Datei im macOS-Temp-Verzeichnis
SpeicherdauerWird nach Transkription sofort gelöscht
RechtsgrundlageArt. 6 Abs. 1 lit. a DSGVO (Einwilligung)

4.2 Transkribierter Text

EigenschaftDetails
VerarbeitungWird in die macOS-Zwischenablage kopiert
Lokaler VerlaufLetzte 5 Einträge, nur lokal, löschbar
Dauerhafte SpeicherungNein — bei App-Neustart geleert

4.3 API-Schlüssel

Verschlüsselt im macOS-Schlüsselbund. Werden nie geloggt, nie in Backups exportiert.

4.4 Logdateien

Lokal im Temp-Verzeichnis. Nur Metadaten (Zeitstempel, Textlängen) — keine Transkriptionstexte in Release-Builds. Werden nie übermittelt.

5. Datenübermittlung — je nach Backend

5.1 OpenAI Cloud (optional)

Audio wird an die OpenAI Whisper API gesendet. Bei Modi wird Text zusätzlich an die Chat API gesendet.

Empfänger: OpenAI, L.L.C. (USA)
Rechtsgrundlage: Art. 6 Abs. 1 lit. a DSGVO
Drittlandübermittlung: EU-Standardvertragsklauseln (SCCs)
OpenAI Datenschutz · DPA

Hinweis (Apple Guideline 5.1.2(i)): Durch Wahl des OpenAI-Backends werden Daten an einen Drittanbieter-KI-Dienst übermittelt. Widerruf jederzeit über die App-Einstellungen.

5.2 Eigener Server (optional)

Audio wird an die vom Nutzer konfigurierte URL gesendet. Der Nutzer ist für Datenschutz selbst verantwortlich.

5.3 WhisperKit — lokal (offline)

Keine Datenübermittlung. Verarbeitung ausschließlich auf dem Mac. Datenschutzfreundlichste Option.

5.4 Ollama — lokaler KI-Rewrite

Läuft auf localhost. Kein Netzwerkverkehr nach außen.
