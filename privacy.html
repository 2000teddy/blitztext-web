Privacy Policy

1. Controller (Art. 4(7) GDPR)

Christian Ullmann
Email: axxsys@gmail.com

2. Subject Matter

Blitztext Lite is a macOS menu bar app for speech-to-text dictation. The app records speech via the microphone, transcribes it, and places the result on the macOS clipboard.

3. What Blitztext Does NOT Do

  • No tracking, no telemetry, no analytics
  • No advertising
  • No account or registration required
  • No iCloud sync
  • No sharing with third parties — except the backend chosen by the user
  • No cookies, no device/user IDs

4. What Data Is Processed?

4.1 Audio Recording

PropertyDetails
CollectionOnly while the user actively holds the hotkey
StorageTemporary .m4a file in macOS temp directory
DurationDeleted immediately after transcription
Legal basisArt. 6(1)(a) GDPR (consent)

4.2 Transcribed Text

PropertyDetails
ProcessingCopied to macOS clipboard
Local historyLast 5 entries, local only, deletable
Persistent storageNo — cleared on app restart

4.3 API Keys

Encrypted in macOS Keychain. Never logged, never exported in backups.

4.4 Log Files

Local in temp directory. Only metadata (timestamps, text lengths) — no transcription text in release builds. Never transmitted.

5. Data Transmission — By Backend

5.1 OpenAI Cloud (optional)

Audio is sent to the OpenAI Whisper API. For modes, text is additionally sent to the Chat API.

Recipient: OpenAI, L.L.C. (USA)
Legal basis: Art. 6(1)(a) GDPR
Third-country transfer: EU Standard Contractual Clauses (SCCs)
OpenAI Privacy · DPA

Notice (Apple Guideline 5.1.2(i)): By choosing the OpenAI backend, data is transmitted to a third-party AI service. Revocable at any time via app settings.

5.2 Custom Server (optional)

Audio is sent to the URL configured by the user. The user is responsible for data protection compliance.

5.3 WhisperKit — Local (offline)

No data transmission. Processing exclusively on the Mac. Most privacy-friendly option.

5.4 Ollama — Local AI Rewrite

Runs on localhost. No external network traffic.
